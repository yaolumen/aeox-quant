## 安装（TradingView）

1. 打开 TradingView → 底部 **Pine Editor**
2. 新建脚本，粘贴对应 `.pine` 文件全部内容 → **Save** → **Add to chart**
3. 建议顺序：主图先加 Lighthouse；副图按需加 Confluence / Regime / Flow / Risk
4. 每个图表布局（Layout）可保存为模板，一键切换币种/周期

## 设置 Alert（付费核心功能）

对每个指标：图表右键 → **Add alert** → Condition 选对应指标 → 选择信号（BUY / SELL / STOP / TP）→ 通知方式（App 推送/邮件/Webhook）。一次设置，TradingView 7×24 云端盯盘，无需开页面。

**触发频率务必选 "Once per bar close"**：信号按当根收盘价计算，盘中数值会实时变动（属正常现象，非重绘）；收盘触发才能保证 alert 与网页引擎同口径，也避免盘中信号闪变造成误操作。

建议至少设置：Lighthouse 的 BUY / SELL / STOP 三个 alert。

## 推荐实战组合（数据支持）

5 个脚本不是平行的 5 个信号源，而是一套分工系统。以下定位基于 2026-09 实测（5 币 × 417 天 1H，同引擎同成本：0.1%/边 + 5% 止损）：

| 角色 | 脚本 | 实战用途 |
|---|---|---|
| **入场引擎（核心）** | **Lighthouse** | 唯一跨窗口正期望的入场信号（胜率 65-84%、回撤 <8%）。BUY alert 就是行动信号，ATR 止损线直接可执行 |
| 环境闸门 | Regime | 低于 -40 时不开新仓（深熊窗口实测：把亏损配置从 -18% 救回 -1%、回撤 -16pp） |
| 风险工程 | Risk（网页端查） | 非信号：2×ATR 止损距离 → **仓位 = 单笔风险预算 ÷ 止损距离**（例：1% 风险 ÷ 5% 止损 = 20% 仓位） |
| 共振确认（可选） | Confluence | 堆叠确认层，**不建议单独作为入场信号**：单独跑深熊窗口净 -18.4%（222 笔、胜率 28%），叠加 Regime 过滤后仍为 -0.6%——它的价值是"多方共识确认"，配合快出开关可作为高胜率工具（胜率 51-62%，期望约打平，适合心理上需要高胜率的用户） |
| 量能背书（可选） | Flow | 最弱一环：代理数据、无独立验证，仅供观察。其精神已内置在 Lighthouse 的"成交量确认"开关中 |

**免费账户（2 指标上限）推荐挂法：主图 Lighthouse + 副图 Regime。** Confluence / Flow / Risk 用 quant.aeox.uk 网页端查看（免费、无限叠加）。

## 状态机（买 / 不买 / 卖）

| 状态 | 判定 | 动作 |
|---|---|---|
| ✅ 买入 | 主图出现 BUY 三角 **且** 副图 Regime > -40 | 买入；止损放图上红色 ATR 止损线；仓位 = 单笔风险预算 ÷ 止损距离 |
| ❌ 不做（99% 的时间） | 没有 BUY 三角 | 什么都不做。1H 上约每币每月 1 次入场——等 alert，不盯盘 |
| ❌ 放弃 | BUY 三角出现但 Regime ≤ -40 | 跳过该信号（罕见冲突态：趋势守卫与 Regime 分歧时，Regime 一票否决） |
| ❌ 永不 | 价格在青色 SMA100 下方 | 守卫已自动封锁，不会出现 BUY |
| 🔴 卖出 | SELL 三角 / STOP 叉 / TP 叉（任一出现） | 无条件执行，不犹豫不抗单 |

时间纪律：所有信号按当根收盘确认（alert 选 "Once per bar close"），盘中数值变动不作为依据。周期纪律：Lighthouse 只在 1H 使用（4H 已被实验证伪，周期错位）。

## 与 quant.aeox.uk 的一致性（诚实清单）

- **信号标记 = 引擎口径（重要）**：BUY/SELL 标记按持仓状态配对——首个信号开仓、持仓时的卖出才算离场、重复交叉不显示（与网页回测箭头一致）。指标原始交叉（如无持仓时 RSI 冲高）不是可操作信号，故不作标记、不触发 alert
- **Lighthouse / Regime / Risk**：与网页默认设置**逐 bar 一致**（同数学、同阈值）。回测对比时网页止损设为与脚本相同的档位
- **Confluence**：TradingView 不提供资金费率数据，费率因子保持中性 50 —— 与网页"费率不可用"的降级模式**完全一致**（网页在 fapi 不可达地区同样如此）。网页演示版费率 z-score 使用全部历史（有轻微前视），Pine 版即三因子模式
- **Flow**：网页读币安 K 线的真实 taker 买入量；TradingView 不暴露 taker 数据，Pine 版使用标准蜡烛解剖代理（CLV：收盘位置在当根高低区间的位置）。信号类似，不逐 bar 相同
- **数值预热差异**：网页 EMA 用 SMA 种子初始化，Pine 用标准 EMA —— 前 ~3×周期根可能有微小差异，随后收敛
- 网页回测口径：只做多、bar 收盘进出场、盘中止损、0.1%/边手续费。在 TradingView 复现时用 Strategy Tester 按同口径设置

## 使用工作流（与网页 #guide 区一致）

1. **先筛后做**：用网页扫描中心排行选候选
2. **图表验证**：核对 BUY/SELL/STOP 标记，<30 笔平仓交易的样本视为统计单薄
3. **止损匹配**：用 QS Risk 的建议距离校准止损档位（Lighthouse 可直接开 ATR 自适应止损）
4. **按回撤定仓位**：历史最大回撤是风险预算，按"历史重演也输得起"定仓
