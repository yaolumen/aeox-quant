# Exit-Swap 实验：入场/出场指标分离回测 — 2026-09-17

> 问题：Lighthouse / Confluence 的自带卖出是否过早（BUY 标记后还有行情）？
> 换用另外三个指标（Regime / Flow / Risk）作为退出参考，胜率或盈利能力能否提高？

## 实验设计

- 入场指标：Lighthouse（lh）、QS Confluence（qs，funding 降级三因子）
- 出场信号：自带（baseline）/ qs>80 / flow<-20 / regime<-40 / rsi14>70 / none（只靠止损）
- 引擎：与页面同款（long-only、bar close 进出、盘中止损悲观优先、0.1%/边、止损 5%、末 bar 强平计入）
- 数据：5 币（BTC/ETH/SOL/BNB/XRP）× 4 个窗口：1H×3000（~125 天，牛尾）、1H×6000（~250 天，牛转熊）、1H×10000（~416 天，深熊主导）、4H×6000（~1000 天，牛主导）
- 工具：`lab/exit-swap.mjs`（`node lab/exit-swap.mjs --pages N --stop 5 --tf Xh`）

## 结论

### 1. 用户的观察是真的，但结论不成立

"BUY 标记后还有一段行情"——真实。1H/3k 窗口里慢出场期望翻 2~10 倍（lh→none +11.58 vs 自带 +1.10）。
**但这是牛市窗口的幸存者视角**。同一组合在深熊窗口（1H/10k，hold -11%~-59%）期望 -2.14%/笔、回撤 34%（自带仅 7.8%）、胜率 9%。
慢出场 = 高 beta：牛市吃肉、熊市连本带利吐回。**四个窗口中没有任何一种出场 swap 能稳定打败自带出场。**

### 2. 唯一跨窗口稳健的是 Lighthouse 自带快出场

1H 三个窗口全部正期望（+1.10 / +0.30 / +0.14），且回撤最低（4~8% vs swap 组合 11~34%）。
RSI(4)>70 不是"卖太早"，是**为锁利付的小额保险费**——截断左尾的代价。这直接强化了风险工程叙事。
（4H 自带转负属预期：Lighthouse 主场是 1H，SMA100 在 4H ≈ 16 天，周期错位。）

### 3. 胜率可以买，但买不到钱

qs→rsi14>70 把胜率从 28% 稳定拉到 51~62%（三个 1H 窗口、372 笔样本）——**胜率翻倍是真实且稳定的**。
但期望从未更好（-0.49 vs -0.29）。快出场锁小利提高胜率、降低单笔期望，正是"买胜率不买钱"的教科书取舍。

### 4. 另外三个指标的正确角色不是退出信号

- **Regime<-40 当出场**：太慢。等 EMA50/200 差值跌到 -40，利润已回吐大半（lh→regime 深熊窗口 -1.32）。
- **Flow<-20 当出场**：噪声太多，频繁误触发（1H 全窗口负期望）。
- **Risk**：本来就是止损工程（仓位/止损距离），不是方向信号。
- **它们的正确用途是入场过滤**：XRP 在全部 11 种组合中全线亏损（深熊 -59%），证明"该不该交易"比"何时退出"更根本——这正是 Regime 的本职（四层分工：Regime 该不该 → Confluence 何时进 → Flow 有无背书 → Risk 止损放哪）。

## 对产品决策的建议

1. **不加"卖出指标选择"（swap 型选项）**：数据不支持，会引导用户过拟合，且破坏"出场工程"的叙事完整性。
2. **可选：加"快速了结模式"（qs→rsi>70 quick-exit）**：胜率翻倍现象三窗口稳定，是真实取舍。若加，UI 必须诚实标注"提高胜率、不提高期望，适合心理上需要高胜率的用户"。
3. **更值得做的是 Regime 入场过滤**（如 lh 买入时要求 Regime>-40）：这是"借助另外三个指标"的正确姿势，XRP/SOL 深熊数据支持。留待下一轮实验（exit-filter）验证。
4. 4H/1D 不做 Lighthouse 推广（周期错位已证实）。
